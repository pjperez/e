# e — brand kit

Everything here is generated by [`logo.py`](logo.py). Nothing is hand-drawn, so
the mark can be re-cut at any weight or size without redrawing it.

```bash
python logo.py            # rebuild brand/* and ../public/e.svg
python logo.py --review   # contact sheet of the six candidate cuts -> out/index.html
```

`logo.py` needs nothing but the Python standard library.

## The idea

*e* and φ meet in exactly one place: the **logarithmic spiral**.

```
r(θ) = a·e^(bθ)     is golden when it grows by φ every quarter turn
e^(bπ/2) = φ   ⟹   b = 2·lnφ/π ≈ 0.3063489
```

The golden spiral is literally *e* raised to a golden power. φ sets the
proportion, *e* does the growing — which is a fair description of an agent
harness too. So every measurement in the letter is a power of φ:

| measurement | value                                    |
|-------------|------------------------------------------|
| x-height    | `2R`, the mark's bounding circle         |
| weight      | `R/φ³`, modulated `×φ` on the stress axis|
| stress      | tilted `360/φ⁸ ≈ 8.2°` off vertical      |
| crossbar    | golden section of the counter → eye : counter = `1 : φ` |
| aperture    | `360/φ⁴ = 52.5°` wedge at the lower right|
| tile radius | `size/φ³`, with the mark inset `size/φ³` |

`brand/e-construction.svg` draws all of it.

## Files

| file                     | use |
|--------------------------|-----|
| `brand/e-mark.svg`       | the mark in `currentColor` — for embedding |
| `brand/e-mark-violet.svg`| on dark backgrounds (`#a78bfa`) |
| `brand/e-mark-ink.svg`   | on light backgrounds (`#0a0b0e`) |
| `brand/e-tile.svg`       | app tile; source for the platform icon set |
| `brand/e-banner.svg`     | README header |
| `brand/e-construction.svg` | the φ construction drawing |
| `../public/e.svg`        | favicon **and** the in-app mark (see below) |

The mark's bounding box is exactly its circle, so `e-mark*.svg` can be dropped
into any layout without trimming or optical re-centring.

## In the app

`public/e.svg` is the single source of truth for the UI mark. The title bar and
the empty state paint it with a CSS mask:

```css
background: currentColor;
mask: url("/e.svg") center / contain no-repeat;
```

so the mark inherits `color` and follows the theme (including the neon one) for
free, and the shape only ships once.

## Platform icons

```bash
npm run tauri -- icon design/brand/e-tile.svg
```

The Tauri CLI rasterises the SVG itself and writes the whole set into
`src-tauri/icons/` (`.ico`, `.icns`, Appx, iOS, Android). Don't hand-edit those
— re-run the command.

## Re-cutting the mark

`MARK` in `logo.py` holds the chosen cut (variant **A**). `build_e()` takes
`weight`, `contrast`, `stress`, `aperture`, `taper` and `cut`; `VARIANTS` holds
the six candidates rendered by `--review`. Change `MARK`, re-run, and every
asset follows.
